artice cream 프로젝트 소개

실행
  index.html을 브라우저에서 열면 됩니다. 설치나 빌드는 필요 없습니다.
  이 디렉터리만 복사해서 정적 사이트로 사용할 수도 있습니다.
  루트 Next.js 앱의 라우트에는 연결하지 않은 독립 소개 페이지입니다.

구성
  index.html          소개 / 진행상황 / 화면 체크 / 남은일의 내용
  style.css           데스크톱·모바일 스타일
  script.js           메뉴 전환, URL 해시, 뒤로 가기 지원
  assets/app-icon.svg 분홍색·노란색 2단 아이스크림 SVG 아이콘
  assets/*.jpg        화면 체크에 사용하는 원본 화면 캡처 5장

참고와 내용 기준
  personal_portfolio_202322585는 읽기 전용으로 참고했습니다.
  상단 메뉴 + 왼쪽 프로필 + 오른쪽 내용 전환 구조만 활용했습니다.
  원본 폴더의 파일, 사진, 동영상은 수정하거나 가져오지 않았습니다.
  AboutMe → 진행상황, Project → 남은일, contact me → 앱 열기로 바꿨습니다.
  모든 앱 열기 링크는 https://artice-cream.vercel.app/로 이동합니다.

  소개·운영 수치·완료 작업·방향 변경·남은일: check.md (2026-10-04 아침 KST 점검 기록)
  분야 이름·색상: lib/color.ts, supabase/seed.sql
  로그인 우선 전환: 현재 소스와 로컬 커밋 4e0fe97에 반영되어 있으므로
  '커밋 전' 문구를 반복하지 않고 배포 상태·전체 로그인 흐름 확인을 남은일로 표시했습니다.
  배포 서비스의 실시간 상태를 조회하거나 진행률을 자동 계산하지 않습니다.
  큰 도입 제목 블록은 제거했으며, 메뉴 전환 시 해당 본문 영역으로 포커스를 옮깁니다.
  기존 public/icon.svg와 원본 포트폴리오는 수정하지 않았습니다.
  아이콘은 루트의 실제아이스크림.jpg를 참고해 얼굴 없이 2단으로 그렸습니다.
  화면 체크는 목록 → 본문 → 퀴즈 → 결과 → 콘 순서로 캡처와 설명을 보여줍니다.
  사진을 누르면 새 탭에서 원본을 엽니다. 원본 JPG는 수정하지 않았습니다.
  목록의 게스트 안내는 로그인 우선 전환 이전 화면임을 별도로 표시했습니다.

수정
